# 🎮 PUPU GAME : Tactical Shooter 2.0

> 미래 지향적 사이버펑크 감성의 전술 슈팅 HTML5/Canvas 웹 액션 게임입니다.

---

### 🚀 [웹에서 바로 플레이하기 (클릭)](https://hungry4089.github.io/PUPU-GAME/)
별도의 다운로드나 설치 없이 브라우저에서 바로 플레이하실 수 있습니다.

[![Play PUPU Game](https://img.shields.io/badge/🎮_PUPU_게임-바로_플레이하기-purple?style=for-the-badge&logo=github&logoColor=white)](https://hungry4089.github.io/PUPU-GAME/)

---

### 💻 내 컴퓨터에서 오프라인으로 실행하기
1. 프로젝트 폴더 내의 **`실행하기.bat`** 파일을 더블 클릭합니다.
2. 기본 브라우저(Chrome, Edge 등)에서 즉시 실행됩니다.

---

### ✨ 주요 기능
- **HTML5 Canvas 렌더링**: 부드러운 60fps 슈팅 액션 및 화려한 파티클 이펙트
- **사이버펑크 사운드**: Tone.js 기반의 다이내믹 BGM & 사운드 이펙트
- **전술 컨트롤**: 키보드 및 마우스 조작을 통한 반응형 액션
